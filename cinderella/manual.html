仙杜瑞拉 Cinderella

舞台控制台使用說明書｜V1.1｜投影・音控・燈光・部署

一、基本規格

四幕英文話劇、五張 16:9 舞台投影背景、20 個劇情提示（C01–C20）。背景只呈現環境，演員、掃把、玻璃鞋等道具均在實際舞台演出。第一幕使用已確認的樸素小屋；第二幕不放南瓜。

二、演出設備

Windows 筆電一台、投影機與 HDMI、音響及喇叭、燈光控制設備（若有）。建議音控／投影一人，燈光一人，道具一至兩人。

三、投影操作

1. 開啟 index.html（Chrome 或 Edge）。2. HDMI 接投影機。3. Windows 按 Win + P 選「延伸」，不要選「複製」。4. 在控制台按「開啟投影視窗」，把第二視窗移至投影螢幕並按 F11。5. 筆電保留控制台，觀眾只看到背景。

四、演出前試音

先按「啟用聲音＋試音」，確認喇叭有聲音；控制台預設音量 45%。如果無聲，檢查 Chrome/Edge 網站音量、Windows 音量混音器、HDMI/喇叭輸出及連接線。聲音不是自動播放，需由操作人員主動啟用。

五、操控原則

不採用固定秒數切幕。演員完成相對應台詞或動作，音控才按「下一提示」。若忘詞或動作延遲，背景先保持不變。暗場換幕通常安排在演員離場、道具組移動時。燈光欄位僅提示工作人員，不會自動控制實體燈具。

六、背景快速切換

保留五張背景快速按鈕：第一幕小屋、第二幕魔法森林、第三幕宮殿、第四幕 A 試鞋小屋、第四幕 B 幸福花園。快速選幕可用於排練、跳幕、演出補救；正式演出以 C01–C20 按序為主。

七、目前音樂版本注意

V1.1 內建的是瀏覽器 Web Audio 合成配樂，不是真人演奏音樂。先前你已表示音樂不夠自然；授權清楚的真人器樂配樂尚未替換，正式演出不應將此版誤認為已完成的新版配樂。

八、GitHub Pages 部署

1. 在 github.com/new 建立名為 cinderella-stage-control 的 Public 儲存庫。2. 將 ZIP 解壓後的 index.html、.nojekyll 及 docs 資料夾上傳到 main。3. Settings → Pages → Deploy from a branch → main → /(root) → Save。4. 等待 Pages 顯示已發布網址，再實際開啟測試。此包本身不代表已上線；GitHub Pages 是網路預覽版本，正式演出建議另外保存離線檔。

九、故障排除

投影顯示控制台：改成 Win + P「延伸」，把投影專用視窗拖到第二螢幕。按鈕無效：先點控制台空白處，確認瀏覽器頁面有焦點。彈出視窗被擋：允許此網站彈出式視窗。音效未出：先點「啟用聲音＋試音」；再檢查喇叭輸出。錯誤換幕：用上一提示或場景快捷鈕修正。

十、正式演出檢查清單

□ 五張背景都正常顯示　□ 觀眾螢幕沒有控制鈕　□ 試音與鐘聲正常　□ 音樂不蓋過學生英文台詞　□ C01–C20 全部試按　□ 開始、暗場、結局可切換　□ 控燈人員收到提示表　□ 備份離線 HTML。
